Dieses Repository enthält die Borg‑Station des 12‑Stations‑Systems.

## Zweck

Die Borg‑Achse (reB) ist Teil des 9×9 → 3×3 → 3×1 Systems und dient als
NC‑fähige Achse mit eigener tmp‑Navigation und Score‑Berechnung.
